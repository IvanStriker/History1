# History1
Сайт с карточками исторических деятелей

ТЗ:
1. Изменить шаблоны `new_item.html`, `new_card.html` и `new_category.html` так, чтобы содержимое полей ввода формы (input, textarea и так далее), а также страницу, на которую перенаправляет кнопка `Сохранить` можно было изменить посредствам механизма наследования шаблонов Jinja2 (extends).
2. Создать шаблоны `edit_card.html` и `edit_category.html`, унаследуй их от `new_card.html` и `new_category.html` соответственно. В них реализуй функционал редактирования конкретных карточки или подборки.
3. В `main.py` модифицируй функции `cards_edit` и `categories_edit` так, чтобы они возвращали соответствующие ранее созданные шаблоны, передавая в качестве параметров все характеристики редактируемого объекта. Индекс редактируемого объекта передаётся как аргумент этих функций.
4. Кнопка `Сохранить` в `edit_card.html` и `edit_category.html` должна отправлять post запрос по адресу `/cards/edit` или `/categories/edit` соответственно. А функции-обработчики в `main.py` должны сохранять изменения в БД, но только если id текущего пользователя совпадает с полем user_id редактируемого объекта.
5. В шаблоны `cards.html` и `categories.html` добавить кнопки со значками `удалить` в правом нижнем углу всех объектов, принадлежащих текущему пользователю. При нажатии сайт спрашивает подтверждения действия, после чего отправляется delete запрос по адресу `/cards/delete` или `/categories/delete`, а в `main.py` функции обработчики удаляют соответствующую запись из БД, а JS-код удаляет эту карту из html-страницы, чтобы не обновлять страницу лишний раз.

Каждый html файл сопроводи css и js файлыми, в старые стили и скрипты внеси все необходимые изменения. НО: СОХРАНИ СУЩЕСТВУЮЩИЙ СТИЛЬ, ПЕРЕИСПОЛЬЗУЙ ИМЕЮЩИЙСЯ КОД КАК МОЖНО БОЛЬШЕ, чтобы не менять стиль.
