# History1
Сайт с карточками исторических деятелей

ТЗ:
Когда на странице `/home` пользователь нажимает кнопку `Начать тренировку`, выводи всплывающее окно, соответствующее сайту в целом по стилю. На нём должна быть форма со следующим содержимым:
1. Подборка, из которой будут взяты карточки для тренировки. В качестве возможных значений для ввода установи названия всех возможных подборок, а также "Все карточки". Если название подборки так велико, что не влезает, то сократи с помощью "...", однако при наведении мыши на этот вариант ответа значение должно раскрываться, пусть даже выходя за пределы элемента. Дай пользователю вводить ответ самому, предлагая наиболее подходящие варианты, но не давай "выбрать" не существующий ответ.
2. Способ составления заданий для тренировки:
    - Все картички из подборки
    - Рандомно
3. Если выбрано "Рандомно", то активным становится ещё одна облость ввода:
    - Количество карточек в выборке (от 1 до размера подборки)
4. Для облегчения задачи, возможно, стоит создать подборку "Все карточки" в БД, добавиви туда все карточки (это делается через таблице CategoryCard, устанавливающую соответствие многие ко многим).
5. Внизу находятся 2 кнопки: "Начать" и "Отмена".
6. После нажатия кнопки "Начать", сервер возвращает страницу "/train", передав её шаблону массив всех индексов выбранных карточек.
