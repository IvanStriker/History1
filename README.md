# History1
Сайт с карточками исторических деятелей

ТЗ:
1. Создать шаблон `new_item.html` extends `base.html` + соответствующие css и js файлы. Он должен содержать пустую форму для создания карточки или подборки (универсальную) и две кнопки: сохранить и отмена.
2. Создать  струницу `new_card.html` extends `new_item.html` + соответствующие css и js файлы. Она должна содержать форму для создания новых карточек. При нажатии кнопки `Сохранить` на сервер по адресу POST -> `/new_card` отправляется запрос, а сервер сохраняет карточку в БД, закрепляя её за текущим авторизованным пользователем.
3. Создать  струницу `new_category.html` extends `new_item.html` + соответствующие css и js файлы. Она должна содержать форму для создания новых подборок. При нажатии кнопки `Сохранить` на сервер по адресу POST -> `/new_category` отправляется запрос, а сервер сохраняет подборку в БД, закрепляя её за текущим авторизованным пользователем.
4. Для авторизованных пользователей сделай 2 кнопки: 
    4.1. В nav bar кнопку "+", нажатие на которую порождает выпадающее меню:
        - `Новая карточка` (-> GET -> `/new_card` -> `/new_card.html`)
        - `Новая подборка` (-> GET -> `/new_category` -> `new_category.html`)
    4.2. В профиле (`/profile`) создать 2 кнопки: `Новая карточка`, `Новая подборка` с таким же функционалом.
5. При нажатии на `Новая карточка`, открывается страница с редактором карточек, где все поля заполнены заглушками или пустые.
6. При нажатии на `Новая подборка`, открывается страница с редактором подборок, где все поля заполнены заглушками или пустые.

Напомню: созданные карточки и подборки должны добавляться в ранее созданную БД!
