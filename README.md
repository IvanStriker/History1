# History1
Сайт с карточками исторических деятелей

ТЗ:
1. С помощью наследования в Jinja2 (%extends%) реализовать иерархию html-шаблонов: 
    - `base.html`: Содержит интерактивный задний фон и панель вкладок (Дом, Настройки, Вход, Регистрация, Профиль). Последнее - только для авторизированных пользователей.
    - `home.html` extends `base.html`: Содержит кнопки `Начать тренировку`, `Подборки` и `Все карточки`.
    - `train.html` extends `base.html`: Содержит 10 заданий (как и есть сейчас).
    - `settings.html` extends `base.html`: Содержит страницу с настройками (пока что только шрифт).
    - `cards.html` extends `base.html`: Содержит страницу со всеми карточками.
    - `categories.html` extends `base.html`: Содержит страницу с тематическими подборками карточек (пока что сделать заглушку).
    - `sign_form.html` extends `base.html`: Содержит заготовку форму для входа или регистрации (только контур формы и кнопки `вход` и `регистрация`, но не остальные внутренности самой формы)
    - `sign_in.html` extends `sign_form.html`: Содержит форму для входа.
    - `sign_up.html` extends `sign_form.html`: Содержит форму для регистрации.
    - `profile.html` extends `base.html`: Содержит данные профиля.

    Для всего, что связано с профилем, пока что сделай заглушки. Позже будем обновлять структуру БД и тд и тп...
2. Для каждого из html-файлов сделай парный css и js. Сохрани ВСЕ ВСЕ ВСЕ ВСЕ стили, использованные в текущей версии проекта, меняй как можно меньше. Если создаёшь новую страницу, выдержи тот же стиль и по максимому переиспользуй уже написанный код.
